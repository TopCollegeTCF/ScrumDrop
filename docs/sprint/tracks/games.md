# Игры и кейсы

**HoMaX** · ветка `feature/games` · файлы `Features/Games`.

| Этап | Задача | Что показать на проверке |
|---|---|---|
| Дни 1–2 | Подготовить два кейса «Орбита» и «Листопад» по 30 монет. Показать для каждого список допустимых наград и их редкость. | Пример на своих данных |
| Дни 3–5 | Написать выбор одного предмета из выбранного кейса. На локальном примере проверить оба кейса и неизвестный ID. | Рабочий сценарий отдельно от соседних модулей |
| Дни 6–8 | Связать POST открытия с кошельком и записью события. Обновление страницы результата не повторяет открытие. | Общий сценарий в pull request |
| Дни 9–10 | Проверка и исправления | Каталог → открытие → результат. Награда принадлежит выбранному кейсу. |
