# Визуал и интерфейс

**Efka** · ветка `feature/visual` · файлы `Views и wwwroot`.

| Этап | Задача | Что показать на проверке |
|---|---|---|
| Дни 1–2 | Сверстать каталог и карточку результата на примерах данных. Сделать чёрный фон, обычный русский текст, символьную фиолетовую волну с зелёной сердцевиной. | Пример на своих данных |
| Дни 3–5 | Подготовить Razor-экраны результата, пустого инвентаря и отказа. Проверить ширину 360 px, клавиатуру и отключение движения. | Рабочий сценарий отдельно от соседних модулей |
| Дни 6–8 | Подключить данные моделей. На экране показать цену до открытия, затем название награды и баланс. | Общий сценарий в pull request |
| Дни 9–10 | Проверка и исправления | Открытие доступно с клавиатуры. Редкость подписана словами. При уменьшении движения интерфейс остаётся понятным. |
