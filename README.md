# ScrumDrop

ScrumDrop — учебный командный проект. Предлагаемая тема первой версии — учёт личных расходов.

## Цель продукта

Помочь пользователю записывать повседневные расходы и видеть, сколько денег он потратил за месяц.

## Первая версия

- Добавление расхода с суммой, датой и категорией.
- Просмотр списка расходов за выбранный месяц.
- Подсчёт общей суммы расходов за месяц.

## Предлагаемый стек

C#, ASP.NET Core MVC, Razor и SQLite.
