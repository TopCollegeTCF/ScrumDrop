# ScrumDrop

ScrumDrop — учебный командный проект по разработке веб-приложения для открытия кейсов с виртуальными предметами. Вдохновились механикой открытия кейсов на [Musor Drop](https://musordrop.ru/musor-drop-cs2).

## Цель продукта

Создать веб-приложение, в котором пользователь может выбрать кейс, посмотреть возможные награды, открыть его и получить случайный предмет в свой инвентарь.

## Первая версия

- Каталог кейсов со списком возможных предметов и их редкостью.
- Открытие кейса со случайным выбором предмета и показом результата.
- Личный инвентарь с выпавшими предметами.
- История открытых кейсов.

## Предлагаемый стек

C#, ASP.NET Core MVC, Razor и SQLite.
